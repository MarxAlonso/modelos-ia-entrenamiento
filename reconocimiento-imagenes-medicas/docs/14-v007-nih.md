## 1. Infraestructura incorporada (reutilizable)

- `preprocesamiento.py` ahora tiene un **registro de datasets** (`DATASETS = {v1, v2}`): cada entrada declara manifiesto, raíz y columna de clase; `cargar_manifiesto(dataset="v2")` normaliza todo a las columnas estándar. Todo el resto del código es agnóstico al origen.
- `entrenar_transfer.py --dataset v2` y `cuantizar.py --dataset v2`.
- **Corrección importante al registro**: `mejor_version` global violaba nuestra regla §4 (no comparar entre datasets). Ahora existe `mejor_por_dataset` y los estados vigente/superada se calculan solo dentro del mismo dominio.

## 4. Análisis (resumen; desarrollo completo en aprendizaje/09)

1. **Etiquetas débiles**: NIH etiqueta por minería NLP de informes → ruido inherente que limita el techo (literatura con dataset completo llega a AUC ~0.76-0.84).
2. **Frontera artificialmente dura**: el mapeo estricto excluyó 50k hallazgos no-neumónicos visualmente similares.
3. **Punto de operación**: weights extremos + t=0.5 → FP masivos; el AUC muestra que el ordenamiento es regular, la calibración no.

4. Fine tuning completo con lr muy bajo (caro en CPU).
