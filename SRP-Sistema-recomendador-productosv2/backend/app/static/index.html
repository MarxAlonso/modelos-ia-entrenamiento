¿Qué le recomendamos a cada cliente?

Un sistema que combina tres modelos Transformer: entiende lo que el cliente escribe, encuentra productos parecidos a lo que busca o compró, y ordena las recomendaciones según la secuencia de sus compras.

Entrada
El cliente

Su historial de compras (en orden) o lo que escribe: “busco aretes de plata para mi mamá”.

Transformer · mmBERT
Laya

Lee el texto y responde preguntas cerradas en una sola pasada: ¿qué categoría? ¿para quién? ¿es regalo? ¿le importa el precio? Sus respuestas se usan como filtros.

Two-tower
